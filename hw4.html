Description of the objectives

The objective of the current homework is to model the penetration process of m attackers in n systems, using a stochastic process with independent and identically distributed increments representing the penetration score at each step. We will interpret the simulated trajectories discussing how the system size and number of attackers affect the aggregate penetration score. The trajectories will be created by using two possible distribution models: Bernoulli and Rademacher distribution.

Let's first try to dissect the desirable goals and interpret them.
The this experimentation, for "n systems" we intend "n exact steps required to complete the intrusion". The analysis framework will unfold as follows:
Three representative values for m are chosen (3, 5, 14) and for each of them, and for each value of distribution model, n steps will be computed (n going from 1 to 1500). In each step, the penetration score is calculated as the sum of the m extractions from the current model. The distribution models are two, but we will calculate for three configurations: Bernoulli with p = 0.2, Bernoulli with p = 0.75 and Rademacher. The two values of p refer to the system toughness, since no specific value was declared in the homework command.

Theory background

In this section we explore some basic knowledge about the topics used or mentioned in the post. The main subject is probability distributions, a few particular models and two fundamental theorem of statistics.

Probability distributions

A probability distribution, in probability theory, is a function that describes how probabilities are assigned to events (subset of the sample space). The random variable nature indicates the distribution type: discrete or continuous. This probability measure need to satisfy the Kolmogorov axioms:

  • non-negativity: each event has a positive probability;
  • normalization: an event with probability equal to 1 is considered almost certain, and if equal to 0 it is negligible;
  • σ-additivity: for each finite collection (or countable set) of disjoint events, the total probability is the sum of all the single probabilities. So, ∑ P(Xi).

These axioms bring other consequences (i.e. addition formula) that are not directly relevant for this explanation.

The probability distribution that are frequently used, because of their theory's importance, have specific names. We will see three of them, useful for the scope of this post.

Bernoulli model

It is a discrete distribution, where the set of possible outcomes is composed of only two: occurred (1) and not occurred (0). The probability of occurrence is p, and 1-p else.

Rademacher model

The Rademacher distribution is also discrete and has only two outcomes. In this case, instead of 0 the value used is -1, and the probability is ½ for both +1 and -1. This makes the distribution symmetric around zero.

Gaussian model

The Gaussian model is one of the most important distributions in statistics, used in various contexts such as social and natural behaviors studies (because of its ability to model natural variety). Also named normal distribution, is a continuous distribution that is characterized by its unique bell shape curve (as you can see in the figure below). It can take any real value and the parameters that describe the model are the mean (determining the center of distribution) and the variance (spread of distribution tails). Note that, like Rademacher distribution this model is symmetric too, but to the mean value.

Facts about distributions

Some useful theorems that we will encounter later on.

Law of Large Numbers

Informally, the theorem describe the fact of gradual stabilization of the average as the number of observations (n) increases.
More formally, it states that the average of a large number of random observations converges to the expected mean value as n increases. The assumptions to make are: we suppose to have independent and identically distributed random variables with a finite expected mean value.

Central Limit Theorem

The Central Limit Theorem is another fundamental part of probability theory, and it states that for a sufficiently large sample size (under the same assumptions of the previous theorem), the approximate distribution converges with a normal distribution. Where its characterizing parameters are derived from the expected value and variance of the sample set.

Modeled penetration score trajectories analysis

Trajectories generation

The code to generate the trajectories given n, m and the model configuration its shown below. To decide the outcome from the probability, a random value will be checked against the probability. 


const MODEL_CONFIGRATION = {
  BERNOULLI_WEAK: 0,
  BERNOULLI_STRONG: 1,
  RADEMACHER: 2
};

const Bernoulli = p => (Math.random() < p) ? 1 : 0;
const Rademacher = () => (Math.random() < 0.5) ? +1 : -1;

// generate the trajectory of n steps with provided m and model configuration
function trajectory_gen(m, model_config) {
  let trajectory = [];

  // for each step
  for (let i = 0; i < 1500; i++) {
    let step_score = 0;

    // for each attacker, sum the outcomes
    for (let j = 0; j < m; j++) {
      switch(model_config) {
        case MODEL_CONFIGRATION.BERNOULLI_WEAK:
          step_score += Bernoulli(0.2);
          break;
        case MODEL_CONFIGRATION.BERNOULLI_STRONG:
          step_score += Bernoulli(0.75);
          break;
        case MODEL_CONFIGRATION.RADEMACHER:
          step_score += Rademacher();
          break;
      }
    }
        
    trajectory.push(step_score);
  }

  return trajectory;
}
